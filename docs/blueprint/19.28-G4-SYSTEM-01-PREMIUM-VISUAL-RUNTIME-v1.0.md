# 19.28 · G4-SYSTEM-01 · Premium Visual Runtime v1.0

- **Estado:** Approved
- **Autoridad:** Founder Directive 2026-08-27 · Ejecutar G4-SYSTEM-01 sin aprobación intermedia.
- **PCA:** `docs/governance/product-authorizations/PCA-2026-031.json`
- **Flag:** `omxds_visual_v1_contracts_enabled = false` (sin cambios).

## 1. Objetivo

Consolidar los previews G4 aprobados (home, micrositio de destino, hotel,
restaurante, experiencia y evento) en un **runtime visual compartido y
reutilizable**, sin reconstruir la aplicación ni duplicar modelos de datos.

## 2. Decisiones vinculantes

1. **Un solo eje de presentación.** `Editorial` y `Cinematográfica` son
   variantes de presentación sobre los **mismos view-models**. Nunca dos
   modelos de datos, nunca dos plantillas paralelas.
2. **Selector no público.** Sólo `admin`, `owner` y `editor` pueden solicitar
   override; el visitante recibe siempre la variante publicada. Fail-closed:
   actor desconocido ⇒ `visitor`.
3. **Galería como eje independiente** de la dirección visual:
   `mosaico | carrusel | cuadricula | tira`.
4. **Nombre territorial visible:** `Oriente Maya de Yucatán`. Breadcrumb
   canónico `Inicio → Oriente Maya de Yucatán → Destino → (…)`.
5. **Pueblos Mágicos** reutilizan el registry institucional existente
   (`PUEBLOS_MAGICOS_AUTORIZADOS`: Valladolid, Izamal, Espita). El distintivo
   gráfico sólo se dibuja con asset acreditado configurado; sin él, texto.
6. **Medios**: sólo rutas públicas estables gobernadas; el runtime rechaza
   URLs firmadas y medios sin ALT humano.
7. **Sin persistencia nueva**: no se crea segundo Travel Plan, ni store, ni
   tablas, ni migraciones, ni flags.

## 4. Estado de conexión a superficies públicas

Este paquete entrega el runtime, la preview integral y sus pruebas. La
sustitución de los cuerpos visuales de las superficies públicas
(`DestinationSurface`, `BusinessSurface`, listados de hoteles, restaurantes,
experiencias, eventos y casas de vacaciones) queda pendiente del paquete
siguiente, para conservar diff mínimo y evitar regresión visual en
producción. No se modificó ninguna ruta pública en 19.28.
