## 1. Veredicto histórico

El Preflight definitivo de I3 quedó en PASS después de cerrar la remediación L0+L1 del lint. Ese PASS habilitó únicamente la solicitud de implementación separada de I3-0; no autorizó I3-A/B/C/D, activación pública ni producción.

Este documento registra el resultado ya aprobado. No afirma una nueva ejecución en la reconciliación documental actual.

## 2. Arquitectura confirmada

- ownership de Experience resuelto a favor de Product para `product_type` experiencia/tour;
- cuatro renderers: Destination, Business, Product y Event;
- tres adaptadores: Hotel→Business, Restaurant→Business y Experience→Product;
- ocho superficies semánticas;
- división obligatoria I3-0/A/B/C/D;
- misma entidad y URL para Standard/Premium;
- cero renderers paralelos para adaptaciones.

## 3. Frontera de riesgo confirmada

`omxds_visual_v1_contracts_enabled=false`

El lector existente:

- evalúa del lado servidor;
- requiere `true` booleano explícito;
- devuelve `false` si faltan credenciales o setting;
- devuelve `false` ante error o excepción;
- conserva fallback exacto con OFF;
- no concede permisos de Builder, Premium, Commerce o publicación.

No se autorizó crear otro flag.

## 4. Baseline de lint L1

La remediación aprobada en `18.36`:

- excluyó únicamente evidencia vendorizada/minificada y tipos Supabase generados;
- registró deuda histórica por archivo, regla y severidad;
- añadió gate `no new lint debt`;
- exigió cero errores en archivos nuevos o modificados por I3;
- no ejecutó autoformateo global ni limpieza masiva.

## 7. Stop conditions

Cada lote debía detenerse si:

- el SHA base no coincidía;
- se necesitaba un archivo fuera de la lista cerrada;
- aparecía una ruta, loader, consulta, schema, API o dependencia nueva;
- el fallback OFF cambiaba HTML, renderer, canonical, metadata, JSON-LD o SEO;
- una fuente ausente producía información simulada;
- aparecía Commerce, reserva, precio o disponibilidad no autorizada;
- lint, suites previas, typecheck, build o gobernanza no quedaban en PASS.

## 8. Límites conservados

El Preflight no autorizó:

- implementación conjunta de I3;
- activación del flag;
- producción o publicación pública;
- datos reales;
- Builder;
- Commerce o reservaciones;
- Visitor Journey Intelligence;
- Zazil Tunich;
- Premium fuera de su Founder Review y lote específico.

La incorporación de `18.35` restaura la pieza documental citada por `18.36–18.41`. No ejecuta nuevamente el Preflight, no cambia su veredicto histórico y no concede permisos nuevos.
