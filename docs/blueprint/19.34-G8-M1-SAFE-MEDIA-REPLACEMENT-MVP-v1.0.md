## 1. Propósito

Habilitar el flujo mínimo **seguro** para seleccionar, subir, aprobar y
sustituir imágenes dentro de los ocho presets premium del Experience Builder,
sin borrado definitivo, sin publicación y sin tocar páginas públicas.

Cierra: DEF-M-01, DEF-M-02, DEF-M-04, DEF-M-05, DEF-M-06, DEF-M-07, DEF-M-08 y
DEF-M-10.

## 2. Reglas vinculantes

1. **Subida crea activo nuevo.** Cada subida genera una ruta única, un
   `media_asset` nuevo y `upsert=false`. Nunca se sobrescribe un binario.
2. **No sobrescritura ni borrado.** Sustituir la imagen de un slot cambia
   únicamente la referencia del borrador; el activo anterior permanece intacto
   y visible en la Biblioteca.
3. **Aprobación antes de publicación.** Todo activo nace `status=draft` +
   `review_state=unreviewed` y no puede seleccionarse para un slot hasta que un
   rol administrativo ejecute `Aprobar para uso público`.
4. **Metadata de derechos obligatoria.** ALT, autor, crédito, fuente, licencia,
   lugar, fecha, naturaleza y confirmación de derechos. Fail-closed: una imagen
   generada con IA nunca puede declararse documental; una fotografía documental
   sin fuente, autor o licencia se rechaza; un crédito no puede acreditar a un
   fotógrafo no declarado como autor.
5. **ALT y crédito nunca se descartan.** Se propagan del activo al slot; el
   override de ALT es por slot y el ALT original se conserva en `media_assets`.
6. **Punto focal.** `focal_x` / `focal_y` en rango 0–1, default 0.5/0.5,
   almacenados en `metadata` (sin columnas nuevas) y traducidos por el renderer
   a `object-position`.
7. **Separación léxica.** «Quitar de este slot» ≠ archivar ≠ eliminar. La
   palabra «Eliminar» queda prohibida para vaciar un slot.
8. **Separación de funciones.** El editor territorial sube y propone; no
   autoaprueba su propio activo salvo `super_admin`.

## 3. Contrato técnico

| Pieza | Responsabilidad |
| --- | --- |
| `src/lib/media/slot-media.ts` | Codifica/decodifica ALT, crédito, naturaleza, revisión y focal sobre la URL estable del slot; deriva `object-position`. |
| `src/lib/experience-builder/media-rights.ts` | Reglas puras de derechos y naturaleza, compartidas por cliente y servidor. |
| `src/lib/experience-builder/studio-media.functions.ts` | `listStudioMediaLibrary` (filtros aprobadas/pendientes/conceptuales, sólo `deleted_at IS NULL`), `signStudioMediaUpload`, `registerStudioMedia` (SHA-256 en servidor, draft/unreviewed, bucket/path/bytes originales, creador), `approveStudioMedia` (rol administrativo, validación de metadata, `reviewed_by` / `reviewed_at`). |
| `src/components/experience-builder/MediaPickerDialog.tsx` | Diálogo único: búsqueda, filtros, miniaturas, estado, crédito, procedencia, indicador IA/conceptual, subida con metadata y punto focal, acción de aprobación. |
| `src/components/experience-builder/AutoInspector.tsx` | Botón primario `Seleccionar o subir imagen`; ficha del slot con miniatura, ALT, crédito, naturaleza, revisión y focal; `Cambiar imagen` y `Quitar de este slot`. |

## 4. Prohibiciones ejecutadas

- Eliminado del inspector todo uso de `FileReader`, `data:` URI y base64
  incrustado en la composición.
- Ningún activo no aprobado puede seleccionarse para un slot.
