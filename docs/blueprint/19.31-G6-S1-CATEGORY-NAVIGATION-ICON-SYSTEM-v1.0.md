## 1. Identidad

**Universal Tourism Iconography with Yucatecan Textile Accent v1.0.**

Sistema canónico, inmutable y fail-closed de íconos universales de categoría
turística. El símbolo es universalmente legible (cama, tenedor, pin, cenote,
pirámide); la identidad regional se expresa exclusivamente como acento textil
de bordado yucateco, nunca como sustitución del símbolo.

## 2. Reglas vinculantes

1. **Autoridad única.** `src/lib/omxds/category-icon-registry.ts` es la única
   fuente de verdad. Prohibidos mapas paralelos (`CATEGORY_ICON_MAP`),
   diccionarios locales, slugs PascalCase y fallbacks genéricos (`Layers`).
2. **Fail-closed.** Un slug no registrado no renderiza símbolo; la etiqueta de
   texto permanece siempre en el DOM. Nunca se sustituye por un ícono genérico.
3. **Un solo wrapper.** Todo consumo pasa por `TourismCategoryIcon`; toda
   rejilla de categorías pasa por `CategoryNavGrid`.
4. **Formato técnico.** Los 22 símbolos son componentes React `.tsx`
   (`src/components/omxds/icons/*`). El proyecto no dispone de loader SVG→React
   en Vite; no se introduce ninguna dependencia nueva.
5. **Contraste.** El trazo significativo usa siempre la variante operativa
   acreditada (≥3:1). Los tonos `mutedPink`, `limestoneGold`, `waterTurquoise`
   y `antiqueGold` sólo se emplean como acento textil.
6. **Tamaños.** `compact` 32–40 px · `standard` 40–48 px · 56 px sólo con
   `spaceCredited`. Área táctil mínima 44 px en el contenedor.
7. **Evolución sin duplicación.** La familia crece por `variant`,
   `scheme`, `monochrome` y nuevas entradas del registry; prohibidos sufijos
   `-v2`, `-pro`, `-next`.

## 3. Alcance ejecutado (G6-S1)

- 22 símbolos canónicos.
- Registry congelado (`Object.freeze`) con paleta congelada y tokens
  documentados.
- `TourismCategoryIcon` (wrapper único) y `CategoryNavGrid` (rejilla
  responsive, modos `navigate` y `select`).
- Adopción en: `DiscoveryNavigator`, `InlineCategoryExplorer`,
  `CategoriaCard`, `discovery-navigator.functions.ts`, `mocks/categorias.ts`,
  `g4-home-premium-preview`, `g4-destination-microsite-preview`.
- Catálogo interno no indexable `/lovable/g6-category-icon-catalog`.
- Contrato `scripts/omxds/g6/category-icon-system.contract.test.ts` y evidencia
  `scripts/omxds/g6/category-icon-system.evidence.mjs`.

## 4. Fuera de alcance

Datos, migraciones, backend, storage, activación del flag, merge, despliegue,
publicación y cualquier ícono fuera de las 22 categorías registradas.

## 5. Validación

`bun run lint`; `bun run typecheck`; `bun run build`; `bun run validate:g6:s1`;
`bun run governance:check`; `bun run governance:product-check`.

## 6. Rollback

Revertir las rutas del manifiesto autorizado. Al ser un sistema fail-closed y
aditivo, la reversión restituye el estado previo sin pérdida funcional: las
etiquetas de texto de categoría nunca dependieron del símbolo.
