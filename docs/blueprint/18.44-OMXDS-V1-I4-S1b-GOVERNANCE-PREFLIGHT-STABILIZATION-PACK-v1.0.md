## Decisión

Founder autoriza exclusivamente estabilizar la fábrica de validación previa a I4-0. Este lote no implementa Builder, superficies, datos, medios ni cambios visuales; corrige procedencia gobernada, unifica la validación local y CI, y añade un gate fail-closed para paquetes de cambio.

## Hallazgo que origina el lote

El preflight sobre la base autorizada confirmó que 07, 08 e inventario se regeneraban sin deriva de contenido, pero conservaban procedencia histórica o de worktree que los validadores no rechazaban. También confirmó que GitHub Actions ejecutaba sólo el subconjunto de gobernanza, mientras la validación integral local incluía lint, contratos OMXDS, typecheck y build. No existía un control genérico que comprobara conjuntamente base, allowlist, cantidad de archivos, referencias prohibidas y árbol candidato antes del commit.

## Contrato de estabilización

- `06-BLUEPRINT-MASTER-INDEX.md`, el glosario, el ADR de dominios y el árbol gobernado son fuentes canónicas.
- 07 y 08 proyectan esas fuentes sobre un sustrato curado congelado mediante SHA-256; cualquier alteración del sustrato fuera del sincronizador produce `FAIL`.
- El inventario registra huellas exactas de su base de generación y usa una fecha determinista derivada de la revisión canónica.
- La ejecución local y GitHub Actions comparten `scripts/governance/validate-full-suite.mjs`.
- El gate de paquete usa un índice Git temporal: no altera el índice real, produce el árbol candidato y falla ante base, rutas, conteo, referencias o árbol distintos de lo autorizado.
- Las pruebas del gate cubren aceptación exacta y rechazo de ruta ajena, referencia prohibida y árbol inesperado.

## Validación obligatoria

- doble regeneración determinista de 07, 08 e inventario;
- gate del paquete sobre las 14 rutas exactas y cero referencias prohibidas;
- lint, I1, I2-A/B/C, I3-0/A/B/C/D, typecheck y build;
- Governance Integrity, Product Authorization Gate y pruebas positivas/negativas del nuevo gate;
- un solo commit y PR borrador, sin archivos ajenos.

## Límites

No se modifica producto, `package.json`, `bun.lock`, rutas públicas, schema, migraciones, datos, dependencias ni flags. `omxds_visual_v1_contracts_enabled` permanece OFF y fail-closed. Este lote no autoriza merge, staging, producción, publicación pública, I4-0, P0, P1, L1, S1, Commerce, reservaciones ni Visitor Journey Intelligence. Si un control exige PCA o una ruta adicional, el lote regresa a Founder Review.
