`vmx.place.premium-q2d` con los datos reales administrados desde

## 3. Reglas fail-closed vigentes

- **Ruta:** borrador, archivado, eliminado, destino inexistente, territorio
  incompatible o zona ajena al destino → 404 público. Nunca se sustituye por
  otra ficha.
- **Preview:** sólo con sesión y rol editorial (`is_editor_or_admin` o
  `poi.write`); muestra el aviso "Borrador · no publicado". No publica.
- **Medios:** únicamente activos propios del lugar bajo el flujo gobernado
  G8-M1 (ALT, crédito, licencia, naturaleza IA, punto focal). Sin fotografía
  acreditada se usa el marcador neutral; prohibido heredar imágenes de
  destinos u otras entidades.
- **Presentación:** Cinematográfica exige portada gobernada aprobada; la
  base de datos rechaza el modo con `cinematic_requires_approved_cover` y la
  superficie cae a Editorial con el aviso oficial del constructor.
- **Secciones:** toda sección sin datos reales se oculta; nunca se rellena
  con fixtures ni contenido de la aprobación visual Q2D-0.

## 4. SEO y navegación

Breadcrumb territorial: Inicio → Oriente Maya → Destino → Zona (opcional) →
Lugar. Canónico `/oriente-maya/{destino}/lugares/{lugar}`. Mientras el lugar
no esté publicado la ruta declara `noindex, nofollow`, no emite JSON-LD
público y no entra al sitemap. El mapeo Schema.org por tipo queda preparado
para la futura publicación (`LandmarksOrHistoricalBuildings`, `Museum`,
`PlaceOfWorship`, `BodyOfWater`, `TouristAttraction`, `Place`).
