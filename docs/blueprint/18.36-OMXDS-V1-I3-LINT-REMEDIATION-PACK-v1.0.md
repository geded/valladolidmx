## Contrato del gate

- `bun run lint` ejecuta ESLint sobre el repositorio mantenido y compara los conteos actuales con `scripts/lint/lint-baseline.json`.
- El baseline conserva `source_commit`, exclusiones exactas, totales y buckets ordenados por archivo, regla y severidad.
- Cualquier bucket nuevo o incremento produce `FAIL`.
- Una reducción de deuda está permitida y no rebasa el baseline.
- Las rutas I3 declaradas en `18.34` producen `FAIL` ante cualquier error o warning cuando son nuevas o modificadas.
- La deuda histórica permanece visible; este lote no declara lint global limpio.
