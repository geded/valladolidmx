Q2C-A **no** ejecuta el corte de URLs, **no** retira los registros históricos de
destino, **no** publica y **no** crea redirects.

### 2.1 Decisión sobre `source_destination_id`

`points_of_interest` **no** tiene columna `source_destination_id` y Q2C-A tiene
prohibida toda migración. La trazabilidad se registra dentro de la columna
existente `metadata` (`jsonb`), bajo la clave `q2c_a`:

```json
{
  "q2c_a": {
    "source_destination_id": "<uuid del destino histórico>",
    "source_destination_slug": "chichen-itza",
    "copied_fields": ["name", "description", "latitude", "longitude"],
    "pending_fields": ["short_description", "highlights", "…"],
    "governance": "PCA-2026-045"
  }
}
```

Es aditivo, no altera esquema, es reversible (borrado de la clave o del
registro) y no toca ningún registro histórico.

### 2.2 Condiciones de parada — todas descartadas

Sin identidad conflictiva; el tipo existe; no hace falta migración; no se
despublica Ek' Balam; no cambia ninguna URL pública; el rollback es íntegro
(cuatro altas nuevas identificadas por slug y por `metadata.q2c_a`); la
idempotencia queda garantizada por slug único.
