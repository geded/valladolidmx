mediante una tarjeta coherente con `DestinationCard`, sin confundir texto editorial
con reputación, premio, disponibilidad o capacidad comercial.

## 5. Contrato y fuentes permitidas

Campos mínimos:

- `family: "business"`;
- identificador interno;
- nombre público;
- categoría gobernada o `null`;
- destino/territorio o `null`;
- resumen editorial o `null`;
- URL canónica interna ya resoluble;
- media elegible o `null`;
- rating sólo con fuente reputacional trazable;
- badges sólo mediante el registry gobernado;
- estado comercial sólo mediante capacidad ya resuelta;
- variante, estado y acciones compartidas.

Reglas:

- ningún dato ausente se sustituye por copy que simule certeza;
- `save`, `add_to_trip` y `discover` permanecen independientes;
- exactamente una acción `discover`;
- analítica sin nombre, email, teléfono, dirección, texto libre o ubicación precisa;
- el adaptador no consulta red ni decide permisos.

## 6. Flag y rollback

- rollback primario: flag `OFF`;
- rollback secundario: revertir sólo el commit I2-B.

No se autoriza otro flag.

## 8. Criterios de aceptación

1. `BusinessCardContract` reutiliza tipos compartidos de I2-A.
2. `DestinationCard` y sus tests no cambian de comportamiento.
3. `CardAnalyticsEvent.family` admite `destination | business`.
4. Cada evento conserva el `family` recibido; no queda fijado a destino.
5. `EmpresaCard` conserva su API pública y ruta canónica.
6. No aparece una segunda primitive equivalente.
7. Ausencias y datos vencidos se omiten determinísticamente.
8. Rating, badges, premios y capacidades no provienen de copy libre.
9. Acciones independientes y una sola acción dominante.
10. Gate post-login vigente sin rediseño.
11. Sol/Luna y accesibilidad cumplen G1.
12. 390/1440 y zoom 200 % sin pérdida funcional.
13. Analítica sin PII.
14. Fixtures completamente ficticios.
15. Flag OFF preserva baseline y fail-closed.
16. I2-A, I2-B, typecheck y build pasan.
17. Gobernanza y Product Authorization Gate pasan.
18. Diff sin superficies, Premium, datos reales, rutas ni otras tarjetas.

## 9. Stop conditions

Detener y regresar a Founder Review si:

- se requiere schema, API, RLS, ruta, dependencia o flag nuevo;
- la generalización analítica rompe I2-A;
- `EmpresaCard` no puede conservar su API pública;

- un dato de confianza carece de fuente gobernada;
- aparece PII en analytics;

- el Product Authorization Gate exige una ruta no declarada.
