## 1. Decisión Founder

Founder autoriza implementar de punta a punta exclusivamente I4-A sobre la base exacta. Este pack incorpora el addendum Founder del 2026-08-04: el alcance sustituye las quince rutas candidatas de `18.47` por exactamente dieciséis, agregando únicamente `scripts/omxds/i4/editorial-builder.evidence.mjs` para que la evidencia histórica de I4-0 reconozca los cuatro consumidores cerrados de I4-A sólo cuando `PCA-2026-013` esté `Approved`.

La implementación conecta una única policy a Block Registry, Block Library, VisualStudio y `studio.functions.ts`. Todo consumidor adicional falla cerrado. El flag `omxds_visual_v1_contracts_enabled` permanece `false`; no se modifica renderer, ruta, RPC, tabla, RLS, migración, dependencia, lockfile, flag, staging o producción.

## 2. Behavioral Change Statement

Antes de I4-A, el Studio ofrecía el Registry histórico completo y el servidor guardaba, duplicaba o convertía templates sin aplicar la policy editorial de I4-0. Después de I4-A:

1. la Library presenta únicamente familias runtime autorizadas para la superficie y actor resueltos;
2. VisualStudio previene inserción, edición, movimiento, eliminación, duplicación y reutilización de nodos confinados;
3. el servidor deriva rol y superficie desde RBAC y composición persistida;
4. el árbol se valida antes y después de traducción;
5. medios nuevos deben resolver en `media_assets` y enlaces nuevos deben ser rutas internas canónicas;
6. nodos históricos fuera de allowlist, incluido `vmx.custom.html`, sólo atraviesan guardado si conservan identidad, payload, padre y orden;
7. duplicación y template nuevo no eluden la policy.

La UI es prevención. `studio.functions.ts` conserva la autoridad dura antes de las RPC existentes.

## 4. Fronteras de seguridad

- superficie derivada server-side desde `page_type`; `custom`, `ai_generated` y valores desconocidos fallan;
- actor derivado mediante `has_role`; `business_owner` queda confinado a superficie `business`;
- hosts externos y protocolos `javascript:`, `data:`, `blob:` quedan prohibidos;
- HTML, scripts, estilos, iframes, embeds y event handlers nuevos quedan prohibidos;
- Media Registry se verifica contra `media_assets.storage_path` vigente;
- los valores gobernados no admiten sustitución manual;
- la traducción best-effort no puede saltarse la segunda validación;
- `duplicateComposition` y `markCompositionAsTemplate` validan como contenido nuevo antes de llamar la RPC.
