## 1. Propósito

Establecer, **antes de tocar una sola imagen**, la capa de gobernanza documental que hace utilizables los assets existentes:

1. **Derechos y licencia** declarados por asset (origen, titular, licencia, atribución exigida, uso comercial permitido).
2. **ALT real** (humano o IA aprobada) conforme a `resolveMediaAlt()` — nunca nombre de archivo.
3. **Dimensiones** (`width`/`height`) conocidas y registradas.
4. **Separación explícita** entre **REAL GOBERNADO**, **DEMO** y **FALTANTE**.

Fuera de alcance total: generar, sustituir, publicar o borrar imágenes; crear componentes, rutas, migraciones, RPC o dependencias; iniciar V1-P1.b/c/d/e.

---

## 2. Principios vinculantes aplicados

- **Founder Immutable Original Principle** — ningún binario original se modifica; la remediación es exclusivamente de metadatos y documentación.
- **Founder Transparent Derivation Principle** — no se construye ninguna URL de variante; nada se lee fuera de `resolveMediaSource()` / `resolveMediaAlt()`.
- **Founder Stable Public Asset Contract** — ninguna URL pública cambia.
- **Demo Pack Policy** — el contenido demo se marca como temporal y jamás se promueve a real sin decisión Founder.
- **Infrastructure Freeze** — cero infraestructura nueva.
