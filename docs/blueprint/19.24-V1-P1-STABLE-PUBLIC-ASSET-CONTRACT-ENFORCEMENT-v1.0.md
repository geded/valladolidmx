# 19.24 · V1-P1 · Stable Public Asset Contract Enforcement

**Versión:** 1.0
**Estado:** Approved
**Tipo:** Execution Package
**Dominio:** D07 · Media & Assets
**Autorización:** PCA-2026-026 (Founder Directive 2026-08-25)
**Base gobernada:** descendiente de `f571d4df50ddb2efb2a2102fe3bfd76e1b1230b8`
**Flag:** `omxds_visual_v1_contracts_enabled = false` (antes y después)

---

## 1. Problema

El diagnóstico READ-ONLY previo (H-A … H-E) confirmó que las superficies
canónicas de **Destino** y **Empresa** emitían `og:image` y el campo
`image` de JSON-LD usando como _fallback_ URLs firmadas de Storage con
vigencia de 1 hora (`createSignedUrl(..., 3600)`).

Esto viola el **Founder Stable Public Asset Contract**: una URL firmada
caduca, no es un contrato público estable y contamina el índice de
buscadores, las vistas previas sociales y los agentes de IA.

Adicionalmente, el destino canónico Valladolid conservaba un vínculo con
el asset heredado `57a401dc-68d3-456f-87ba-f5196070376b`, ajeno al
estándar gobernado del pipeline.

## 2. Alcance autorizado

1. Eliminar URLs firmadas de `og:image` y de `image` (JSON-LD) en las
   superficies de Destino y Empresa.
2. Usar exclusivamente la ruta pública estable canónica ya existente
   `/api/public/studio-media/<path>`.
3. Omitir la imagen (fail-closed) cuando no exista asset estable.
4. Desvincular de Valladolid el asset legacy `57a401dc`.

Fuera de alcance: nuevos buckets, nuevas rutas públicas, cambios de
políticas de Storage, publicación en producción, 19.22.c, G4, G5.

## 3. Diseño

### 3.1 Fuente única de decisión

`src/lib/media/stable-public-url.ts` (nuevo) expone:

| Función                                | Responsabilidad                                                                                        |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `toStablePublicMediaUrl(bucket, path)` | Construye la ruta estable sólo para el bucket gobernado `studio-media`.                                |
| `isSignedMediaUrl(url)`                | Detecta marcadores objetivos de firma (`/object/sign/`, `token=`, `X-Amz-Signature`, `Expires=`).      |
| `stableIndexableImageUrl(url)`         | Filtro fail-closed para metadatos indexables: devuelve `undefined` ante cualquier URL firmada o vacía. |

No se crea un mecanismo paralelo de medios: el prefijo es el proxy
público ya existente (`src/routes/api/public/studio-media.$.ts`), y las
variantes derivadas siguen siendo no canónicas.

### 3.2 Superficie Destino

`src/routes/oriente-maya/$destino.index.tsx` conserva
`stableCoverUrl` como fuente primaria y aplica
`stableIndexableImageUrl()` al antiguo fallback `db.hero_url` (que es una
URL firmada), por lo que en la práctica éste ya nunca se indexa.

### 3.3 Superficie Empresa

`BusinessPremiumMediaItem` incorpora el campo aditivo opcional
`stableUrl`. `business-premium-eligibility.server.ts` lo calcula con
`toStablePublicMediaUrl(asset.storage_bucket, asset.storage_path)`. La
URL firmada (`url`) se mantiene **sólo** para el render autenticado del
navegador; los metadatos indexables consumen `stableUrl`.

### 3.4 Datos

Migración idempotente con allowlist por UUID que elimina la fila de
`destination_media` que enlaza Valladolid con `57a401dc`, registra la
causa literal en `content_audit_log` (`media.unlink`) y **no** borra el
`media_asset` ni sus binarios (Founder Immutable Original Principle).

## 4. Invariantes verificadas

- `omxds_visual_v1_contracts_enabled = false` antes y después.
- Ninguna ruta pública nueva; ningún bucket privado expuesto.
- Ningún binario eliminado ni duplicado.
- `validate:i4:d` permanece FAIL-CLOSED por H07/H11/H12 (esperado).
- Sin despliegue ni publicación en producción.
