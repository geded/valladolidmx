- responsive 390 / 768 / 1024 / 1440;

- teclado y foco;
- lector real disponible (VoiceOver, NVDA o TalkBack según dispositivo);
- touch;
- temas Sol y Luna;
- slice vertical completo Draft→Published;
- separación autor–aprobador;
- conflicto, auditoría y rollback;
- revisión de seguridad de operaciones sensibles y ausencia de PII/secrets.
