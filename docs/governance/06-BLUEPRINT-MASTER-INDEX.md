## 3. Contrato del índice

Cada fila incluye los campos mínimos definidos por gobernanza:

- identificador y nombre canónicos;
- versión y estado documental adjudicado;
- tipo, familia y dominio o módulo responsable;
- predecesor y `superseded-by`;
- implementación, migración, pruebas y Completion Report asociados;
- evidencia de autoridad y última revisión.

Semántica obligatoria:

- `Not established` significa que la asociación no fue acreditada en la fuente revisada o no resolvió contra el árbol actual; no afirma inexistencia histórica.
- `Self-contained documentary evidence; external operational artifact not established` acredita evidencia dentro del propio reporte, pero no una prueba externa reproducible.
- Los dominios `D01`–`D14` se rigen por [`ADR-GOV-0001`](../decisions/ADR-GOV-0001-CANONICAL-DOCUMENT-DOMAINS.md); cada documento tiene exactamente un dominio primario.
- `Draft` no invalida el contenido ni la implementación; registra ausencia de autoridad documental suficiente conforme a la reserva aprobada.
- Las dependencias entre documentos pertenecen a `07-BLUEPRINT-DEPENDENCY-MAP.md` y no se infieren desde esta tabla.
