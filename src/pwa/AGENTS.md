# PWA

- Installed-app launch: public navigations use StaleWhileRevalidate with `src/pwa/launch-shell.ts` (tests in `scripts/pwa/`): with no open window the SW serves the stored page only if it contains the currently precached `index-*.js` and (online) was rendered under 45 min ago because signed photo links expire at 2 h, otherwise network first; the root then soft-refreshes data when the page is over 2 minutes old (`data-rendered-at`). Why: iOS stayed black 3–4 s waiting for SSR and fonts, and a copy from another publish would point at retired chunks.
- Updates and expired photos: in the installed app the root registers the SW after ~300 ms and `register-sw.ts` calls `reg.update()` on launch and bfcache resume; `photo-link-recovery.ts` refreshes queries/router at most every 2 min when a signed photo fails, and `EditorialMediaFrame` clears its failed state when its URL changes. Why: `register()` never re-checks an existing registration, so installed apps kept an old copy with expired photo links until reinstalled.
